## Requirements

We need the next tools to develop application:

* [ASDF](https://asdf-vm.com/)
* [Task](https://taskfile.dev/)


## Installation

We should install project environment:

~~~bash
task install
~~~~


## Test

Execute below command to execute test:

~~~bash
task test
~~~~
