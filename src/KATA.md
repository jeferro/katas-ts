# Theatrical Players
====================================

The first chapter of ['Refactoring' by Martin Fowler, 2nd Edition](https://www.thoughtworks.com/books/refactoring2) 
contains a worked example of this exercise, in javascript. That chapter is available to download for free.

The code calculates the invoice for a theater company, including discounts on future contracts.

Currently, the information is displayed via console. The code needs to be adapted so that the information is 
displayed in HTML format.

Since no tests are available, Golden Master tests need to be created to provide test coverage for the code. 
Then, make the requested change.
